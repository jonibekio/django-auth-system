## 🔹 Loyiha haqida
Bu loyiha Django framework yordamida yaratilgan foydalanuvchi autentifikatsiyasi tizimi.  
Loyihada foydalanuvchilar ro‘yxatdan o‘tishi, login qilishi, logout bo‘lishi va profilini ko‘rishi mumkin.  

## 🔹 Funksiyalar
- Foydalanuvchi ro‘yxatdan o‘tishi (Registration)  
- Login va Logout  
- Profilni ko‘rish va tahrirlash  
- Email va parol orqali autentifikatsiya  

## 🔹 Texnologiyalar
- Python 3.x  
- Django 5.x  
- SQLite (yoki xohlagan boshqa DB)  
- HTML, CSS

```bash
